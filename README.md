# 💳 Сайт вместо Telegram-бота (учебный проект)

Это веб‑версия проекта про безналичную оплату: термины, сценарии “как это работает”, сравнение типов эквайринга, викторина, бизнес‑симулятор и статистика.
Сайт выполнен в многострачничном формате (отдельные `.html` для каждого раздела).

## ✅ Что уже работает

- **Глоссарий** (`Термины`): поиск, карточки, отметка “изучено”
- **Как это работает**: роли покупатель/продавец/банк
- **Сравнение**: таблица типов эквайринга
- **Викторина**: вопросы с вариантами, объяснения, лучший результат
- **Бизнес‑симулятор**: расчёт оборота/комиссии/потерь, рекомендация
- **Статистика и достижения**: сохраняются в браузере (localStorage)
- **Проектная часть на главной**: цель, актуальность, задачи, вывод
- **Локальные SVG-иконки и иллюстрации**: без внешних зависимостей

## 🚀 Как запустить

Важно: из‑за загрузки `data/*.json` сайт нужно открывать через локальный сервер, а не двойным кликом по `index.html`.

### Вариант 1 (самый простой): `serve.bat`

1. Дважды кликните `serve.bat`
2. Откройте в браузере `http://localhost:8000`

### Вариант 2: вручную

В папке проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.
